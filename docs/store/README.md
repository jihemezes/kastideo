# Fiche TestFlight / App Store

- `appstore-fr.md`, `appstore-en.md` : textes de la fiche App Store (pour une soumission ultérieure).
- `demo.m3u` : playlist de démonstration publique (revue Apple et captures d'écran).
- `../PRIVACY.md` : politique de confidentialité (FR/EN).
- Captures d'écran : Actions > « iOS (captures d'écran) » > Run workflow (artefact `captures-ios`, iPhone 6,9" et iPad 13").
- « Quoi tester » : automatique à chaque tag `vX.Y.Z-iosN` (job `quoi-tester` de `ios.yml`).
